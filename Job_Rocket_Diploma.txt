ДИПЛОМНАЯ РАБОТА

Тема: Разработка мобильного приложения для автоматизации процессов поиска работы и подбора персонала «Job Rocket»

ВВЕДЕНИЕ

В современных условиях рынок труда претерпевает значительные изменения, связанные с цифровизацией экономики и ростом мобильности трудовых ресурсов. Процессы поиска работы и подбора персонала становятся все более динамичными, что требует внедрения современных программных решений, способных обеспечить оперативное взаимодействие между соискателями и работодателями. Мобильные приложения играют ключевую роль в этой трансформации, предоставляя пользователям удобные инструменты для управления карьерой и поиска талантов в любое время и в любом месте.

Целью данной работы является разработка мобильного приложения «Job Rocket», предназначенного для автоматизации процессов взаимодействия участников рынка труда. Приложение должно обеспечивать эффективный поиск вакансий, управление резюме, коммуникацию между сторонами и администрирование системы.

1. Теоретические основы поставленной задачи, обзор аналогичных решений

1.1. Постановка задачи

Постановка задачи разработки программного продукта «Job Rocket» является ключевым этапом, определяющим структуру, функциональные возможности и требования к системе. В условиях высокой конкуренции на рынке труда возникает необходимость внедрения мобильных решений, способных обеспечить мгновенный доступ к актуальным вакансиям и базе кандидатов. Основная задача заключается в создании мобильного приложения под ОС Android, которое позволит упростить процесс отклика на вакансии, повысить прозрачность взаимодействия и обеспечить надежное хранение данных.

Современные мобильные сервисы по поиску работы направлены на оптимизацию процессов публикации вакансий, создания профессиональных резюме и обмена сообщениями. Подобные системы включают в себя интуитивно понятный интерфейс, механизмы фильтрации по различным критериям (категория, зарплата, тип занятости) и системы уведомлений. Интерфейс «Job Rocket» спроектирован с учетом современных стандартов Material Design, что обеспечивает удобство взаимодействия пользователя с системой на мобильных устройствах.

Функциональные возможности приложения включают регистрацию пользователей с разделением ролей (Соискатель и Работодатель), публикацию вакансий, создание и редактирование резюме, систему «Избранное» для сохранения интересных предложений, а также встроенный чат для обсуждения деталей трудоустройства. Важным аспектом является разграничение прав доступа и обеспечение безопасности персональных данных, что реализуется на базе современных облачных технологий Firebase.

Целью дипломной работы является разработка мобильного приложения на платформе Android, обеспечивающего автоматизацию основных процессов подбора персонала и поиска работы.

Программный продукт реализован с использованием среды разработки Android Studio, языка программирования Java, и облачной платформы Firebase (Firestore, Authentication, Cloud Messaging), что обеспечивает масштабируемость, высокую скорость работы и надежность хранения данных в реальном времени.

Для достижения цели были поставлены следующие задачи:
- провести анализ предметной области и процессов взаимодействия соискателей и работодателей;
- изучить современные технологии разработки мобильных приложений и облачных баз данных;
- спроектировать структуру NoSQL базы данных для хранения информации о пользователях, вакансиях и откликах;
- разработать архитектуру мобильного приложения и его логическую структуру;
- создать удобный пользовательский интерфейс для различных ролей;
- реализовать функционал поиска, фильтрации вакансий и обмена сообщениями;
- обеспечить защиту персональных данных и управление доступом;
- выполнить тестирование приложения и оценку его эффективности.

Способы решения задач:
- использование объектно-ориентированного программирования на языке Java;
- применение компонентов Android SDK для создания нативного интерфейса;
- интеграция Firebase Authentication для безопасного входа пользователей;
- использование Firebase Firestore для хранения и синхронизации данных в реальном времени;
- реализация Push-уведомлений через Firebase Cloud Messaging (FCM) для оперативного информирования;
- применение современных методов тестирования мобильного ПО.

1.2. Описание логической структуры

Логическая структура приложения «Job Rocket» представляет собой систему взаимосвязанных модулей, обеспечивающих разделение функционала между тремя типами пользователей: Соискателем, Работодателем и Администратором.

Начальным этапом работы является экран авторизации. После входа система автоматически определяет роль пользователя.

Соискатель имеет доступ к следующим модулям:
- Лента вакансий: просмотр актуальных предложений с возможностью фильтрации по категориям, графику работы и формату (удаленно/офис).
- Избранное: сохранение вакансий для последующего изучения.
- Мое резюме: конструктор для создания и редактирования профессионального профиля.
- Мои отклики: список вакансий, на которые была подана заявка.
- Чат: прямое общение с работодателями.

Работодатель имеет доступ к:
- Создание вакансии: форма добавления нового предложения о работе с указанием всех условий.
- Мои вакансии: управление опубликованными объявлениями.
- Список откликов: просмотр резюме кандидатов, проявивших интерес к вакансии.
- Управление профилем компании.
- Чат: переписка с потенциальными сотрудниками.

Администратор обладает расширенными правами и управляет системой через панель управления:
- Список пользователей: просмотр и блокировка аккаунтов.
- Список чатов: мониторинг активности и решение спорных вопросов.
- Управление обновлениями приложения.

1.3. Защита и сохранность данных

Безопасность данных в «Job Rocket» является приоритетом, так как приложение обрабатывает персональную информацию пользователей и историю их переписки. Для защиты используются встроенные механизмы Firebase и специфические проверки на стороне клиента.

В приложении реализована многоуровневая система защиты:
1. Аутентификация: Использование Firebase Auth гарантирует безопасное хранение паролей и управление сессиями.
2. Безопасность на уровне БД: Использование Firestore Security Rules позволяет ограничить доступ к данным. Соискатели могут видеть только свои резюме и отклики, в то время как работодатели имеют доступ к информации только тех кандидатов, которые откликнулись на их вакансии.
3. Валидация входных данных: Все поля ввода (телефон, email, зарплата) проходят проверку на корректность формата, что предотвращает ввод неверных данных и ошибки в работе системы.
4. Управление статусом аккаунта: Система поддерживает блокировку и «мягкое» удаление пользователей, что позволяет оперативно реагировать на нарушения правил платформы.

2. Техническая реализация и описание функционала

2.1. Используемые технологии

Разработка приложения велась в среде Android Studio. Основным языком программирования выбран Java в силу его стабильности и широкой поддержки компонентов Android SDK.

Ключевые технологии:
- Firebase Firestore: NoSQL база данных, обеспечивающая хранение вакансий, резюме и сообщений в виде документов и коллекций.
- Firebase Authentication: Сервис для регистрации и входа пользователей.
- Firebase Cloud Messaging (FCM): Система доставки уведомлений о новых сообщениях и откликах.
- GitHub API: Используется для проверки наличия обновлений приложения.

2.2. Проектирование базы данных

В отличие от реляционных баз данных (SQL), в «Job Rocket» используется документоориентированная модель Firestore. Это обеспечивает гибкость при изменении структуры данных без необходимости сложных миграций.

Основные коллекции данных:
- users: данные профиля, роль, статус.
- vacancies: описание вакансий, требования, работодатель.
- resumes: профессиональные навыки и опыт соискателей.
- applications: связи между соискателями и вакансиями (отклики).
- employer_chats: метаданные чатов и сообщения.

3. Охрана труда при работе с мобильными устройствами и ПЭВМ

Разработка и использование мобильного приложения «Job Rocket» предполагает длительную работу за персональными электронно-вычислительными машинами (ПЭВМ) и мобильными устройствами. Обеспечение безопасных условий труда является важным аспектом, направленным на сохранение здоровья пользователей и разработчиков.

Соблюдение требований охраны труда включает:
- Организацию рабочего места: монитор ПЭВМ должен находиться на расстоянии 600-700 мм от глаз, освещение должно быть равномерным, без бликов.
- Режим труда и отдыха: при длительной работе с мобильным приложением необходимо делать перерывы каждые 45-60 минут для снижения нагрузки на зрение и опорно-двигательный аппарат.
- Эргономику интерфейса: цветовая схема «Job Rocket» поддерживает темную и светлую темы, что позволяет снизить утомляемость глаз в зависимости от условий освещения.

Соблюдение данных рекомендаций позволяет минимизировать риски возникновения профессиональных заболеваний и повысить эффективность взаимодействия с программным продуктом.

Приложение
Листинг кода экрана авторизации (LoginActivity.java):

```java
package job.search.app;

import android.content.Intent;
import android.os.Bundle;
import android.widget.Button;
import android.widget.EditText;
import com.google.firebase.auth.FirebaseAuth;
import com.google.firebase.firestore.FirebaseFirestore;
// ... импорты

public class LoginActivity extends AppCompatActivity {
    private EditText editTextEmail, editTextPassword;
    private FirebaseAuth mAuth;
    private FirebaseFirestore db;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_login);

        mAuth = FirebaseAuth.getInstance();
        db = FirebaseFirestore.getInstance();

        editTextEmail = findViewById(R.id.editTextEmail);
        editTextPassword = findViewById(R.id.editTextPassword);
        Button buttonLogin = findViewById(R.id.buttonLogin);

        buttonLogin.setOnClickListener(v -> login());
    }

    private void login() {
        String email = editTextEmail.getText().toString().trim();
        String password = editTextPassword.getText().toString().trim();

        if (email.isEmpty() || password.isEmpty()) {
            return;
        }

        mAuth.signInWithEmailAndPassword(email, password)
                .addOnCompleteListener(this, authTask -> {
                    if (authTask.isSuccessful()) {
                        checkUserRoleAndLogin(mAuth.getCurrentUser(), email);
                    }
                });
    }

    private void checkUserRoleAndLogin(FirebaseUser user, String email) {
        // Проверка роли пользователя в коллекциях admins, employers, seekers
        db.collection("admins").document(user.getUid()).get().addOnCompleteListener(task -> {
            if (task.isSuccessful() && task.getResult().exists()) {
                proceedToLogin("admin");
            } else {
                // Аналогичные проверки для других ролей
            }
        });
    }
}
```

ЗАКЛЮЧЕНИЕ

В ходе выполнения дипломной работы было разработано мобильное приложение «Job Rocket» для платформы Android. Реализованная система автоматизирует ключевые процессы поиска работы и найма персонала, обеспечивая удобный интерфейс и надежную работу с данными.

Использование современных облачных технологий Firebase позволило создать масштабируемое приложение с функциями реального времени, такими как чат и мгновенные уведомления. Проведенное тестирование подтвердило стабильность работы всех модулей и соответствие продукта поставленным требованиям.

Разработанное приложение обладает практической значимостью и может быть использовано как готовый инструмент для связи специалистов и работодателей. В дальнейшем планируется расширение функционала за счет внедрения алгоритмов рекомендаций на основе ИИ и интеграции с профессиональными социальными сетями.
