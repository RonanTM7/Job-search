# Защитная речь для диплома: Приложение "Job Rocket"

## Вступление
Уважаемый председатель, уважаемые члены Государственной экзаменационной комиссии! Вашему вниманию представляется дипломная работа на тему: **"Разработка мобильного приложения для поиска работы и подбора персонала Job Rocket"**.

Актуальность темы обусловлена необходимостью автоматизации процесса взаимодействия между соискателями и работодателями в мобильном сегменте с использованием современных облачных решений.

## Технологический стек
Приложение реализовано на платформе Android с использованием языка программирования **Java**. В качестве бэкенда выбран стек технологий **Firebase**, что позволило реализовать архитектуру Serverless.
- Для хранения данных используется **Cloud Firestore** — документоориентированная NoSQL база данных.
- Аутентификация реализована через **Firebase Auth**.
- Для уведомлений используются **Firebase Cloud Messaging (FCM)**.

## Демонстрация функционала
Одной из особенностей приложения является гибкая ролевая модель: Соискатель, Работодатель и Администратор.

1. **Гостевой доступ:** Чтобы снизить порог входа, реализован анонимный доступ. Гость может просматривать вакансии и фильтровать их по категориям (Бэкенд, Мобильная разработка и т.д.), но для активных действий (отклик, добавление в избранное) требуется авторизация.
2. **Роль Соискателя:** Авторизованный пользователь получает доступ к созданию резюме, управлению списком избранного и системе откликов.
3. **Роль Работодателя:** Работодатель имеет отличный интерфейс. Он может публиковать вакансии, просматривать список откликнувшихся кандидатов и их резюме.

## Технические особенности и коммуникация
Особое внимание уделено **Real-time взаимодействию**. В приложении реализован полнофункциональный чат между соискателем и работодателем, а также чат техподдержки.

С технической точки зрения:
- Сообщения обновляются мгновенно через `SnapshotListeners`.
- Статус прочтения сообщений обновляется пакетами через `WriteBatch` для оптимизации количества операций с БД.
- Реализована сложная логика уведомлений: как внутри приложения, так и через Push-уведомления (FCM).

## Безопасность и отказоустойчивость
Безопасность данных обеспечивается на уровне **Firestore Security Rules**, разграничивающих доступ к документам на основе UID пользователя. Также реализован механизм "мягкого удаления" (soft delete) аккаунтов.

Для обеспечения актуальности приложения разработана кастомная система обновлений: приложение обращается к **GitHub API**, сравнивает текущую версию с последним релизом и предлагает пользователю скачать APK при необходимости.

Также реализована обработка сетевого состояния: при потере интернета приложение блокирует интерфейс специализированным экраном (`NoInternetActivity`) и автоматически восстанавливает работу при появлении сети.
