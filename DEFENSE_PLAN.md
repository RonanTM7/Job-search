# План-шпаргалка для защиты (Job Rocket)

## 1. Вводные данные
- **Тема:** Мобильное приложение Job Rocket.
- **Стек:** Java (Android), Firebase (Auth, Firestore, Messaging), GitHub API.

## 2. Что показать (Демонстрация)
- **Главный экран:** Список вакансий, категории (горизонтальный список).
- **Фильтрация:** Кликнуть по категории "Бэкенд" или "Мобильная разработка".
- **Гость:** Попробовать лайкнуть вакансию без входа -> всплывет тост "Для начала авторизуйтесь".
- **Вход/Роли:** Показать, что у работодателя есть кнопка "Создать вакансию" (+), а у соискателя - "Мои отклики".
- **Чат:** Открыть чат поддержки или работодателя, написать тестовое сообщение (упомянуть Real-time).

## 3. Технические тезисы (Для вопросов)
- **База данных:** Firestore (NoSQL, документоориентированная).
- **Push-уведомления:** Firebase Cloud Messaging (FCM).
- **Обновления:** `UpdateManager` проверяет `latest release` на GitHub.
- **Оффлайн-режим:** `NoInternetActivity` блокирует UI при потере связи.
- **Безопасность:** Firestore Rules (проверка UID), Soft Delete аккаунтов.
- **Архитектура:** Serverless (все на облачных функциях Firebase).

## 4. Возможные вопросы
- **Почему NoSQL?** Гибкость схемы, высокая скорость чтения, легкое масштабирование.
- **Как работает Real-time?** Используется `addSnapshotListener`, который слушает изменения в коллекции Firebase.
- **Как меняется тема?** Через `AppCompatDelegate` и сохранение состояния в `SharedPreferences`.
